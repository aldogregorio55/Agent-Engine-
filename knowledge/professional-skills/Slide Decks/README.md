# Slide Decks

**Main goal:** everything needed to create a strong slide deck — both the *craft* (what makes an individual slide land) and the *production process* (how to build a whole deck with AI agents). Read the craft doc to judge quality; read the pipeline doc to produce one.

## Contents

- [`slide-deck-creation.md`](./slide-deck-creation.md) — **craft & copy principles.** Medium-agnostic rules for writing slides that land: one idea per section, face forward, be specific, one line carries the weight.
- [`slide-deck-production-pipeline.md`](./slide-deck-production-pipeline.md) — **the AI production pipeline.** The `research → draft → verify → build` process for producing a deck with specialist agents, plus the principles that make it work.

The two are companions: the pipeline produces the deck, the craft principles judge whether each slide is any good.
