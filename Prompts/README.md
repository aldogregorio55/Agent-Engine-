# Prompts

This folder stores work-specific prompts — including system prompts, agent instructions, and prompt drafts being reviewed or refined.

## Structure

Each prompt lives in its own subfolder, named after the tool, agent, or use case it belongs to. Include a notes or observations file alongside the prompt where relevant.

## Notes

- Some subfolders are gitignored (e.g. `Regulatory Scanner/`) — check `.gitignore` if a folder isn't tracking.
